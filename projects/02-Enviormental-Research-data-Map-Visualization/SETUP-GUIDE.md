# GitHub Setup Guide

This package gives you two GitHub assets:

1. A public portfolio repository and GitHub Pages website
2. A GitHub profile README

## Part A — Publish the Portfolio Repository

### 1. Create a GitHub account

Create or sign in to your GitHub account.

Choose a professional username. Recommended formats:

- `muhammadputrajundaris`
- `putrajundaris`
- `mpjundaris`
- `muhammad-p-jundaris`

Avoid random numbers unless your preferred name is unavailable.

### 2. Create the portfolio repository

Create a new public repository named:

`environmental-gis-data-portfolio`

Do not initialize it with another README because this package already contains one.

### 3. Upload the files

Upload the contents of this folder to the repository root:

- `README.md`
- `index.html`
- `style.css`
- `script.js`
- `projects/`
- `cv/`
- `assets/`
- `.gitignore`
- `LICENSE`

### 4. Replace placeholders

Search the files for:

`YOUR_GITHUB_USERNAME`

Replace it with your actual GitHub username.

Add your LinkedIn URL after creating or confirming your profile.

### 5. Enable GitHub Pages

In the repository:

1. Open **Settings**
2. Open **Pages**
3. Under deployment, select **Deploy from a branch**
4. Choose the `main` branch
5. Choose the root folder `/`
6. Save

Your website should use a URL similar to:

`https://YOUR_GITHUB_USERNAME.github.io/environmental-gis-data-portfolio/`

### 6. Add repository details

Recommended repository description:

> Environmental GIS, ecological research, water-quality data, and scientific analysis portfolio by Muhammad Putra Jundaris.

Recommended topics:

- `qgis`
- `gis`
- `environmental-science`
- `biology`
- `spatial-analysis`
- `data-analysis`
- `ecology`
- `remote-work`
- `r`
- `excel`

## Part B — Create the GitHub Profile README

GitHub displays a special README on your profile when the repository name exactly matches your username.

Example:

If your username is `putrajundaris`, create a public repository called:

`putrajundaris`

Then copy the file:

`profile-readme/README.md`

into that repository.

Replace:

`YOUR_GITHUB_USERNAME`

with your actual username.

## Privacy Checklist

Before publishing:

- Do not upload raw government laboratory data.
- Do not publish sensitive species coordinates.
- Do not upload private phone numbers unless necessary.
- Do not upload identity documents.
- Do not publish employer-owned SOPs.
- Use public, synthetic, aggregated, or anonymized data.
